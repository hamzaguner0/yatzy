# Running the project

README içindeki kurulum ve platform oluşturma adımlarını izleyin. Önce `flutter pub get`, `flutter analyze` ve `flutter test` çalıştırın. Derleme için hedef platform araçlarını ayrıca kurun.

Windows'ta klasör yolunda tek tırnak varsa Flutter 3.35.5 test dinleyicisi yol üretirken hata verebilir. Test kopyasını tek tırnak içermeyen bir klasörde çalıştırın; asıl dosyaları silmeniz gerekmez.

Bağımlılık ve uygulama sorunlarını düzeltmek için tüm Python/Flutter işlemlerini sonlandıran veya çalışma klasörlerini topluca silen komutlar gerekmez. `flutter doctor` ile araç zincirini kontrol edin.
